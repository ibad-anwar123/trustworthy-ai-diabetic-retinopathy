# trustworthy-ai-diabetic-retinopathy

# Trustworthy AI for Diabetic Retinopathy Grading

A research-oriented AI system for 5-class diabetic
retinopathy grading with calibrated confidence,
confidence-based referral, and Grad-CAM explainability.

## Main Components

- Retinal image preprocessing
- Deep learning classification
- Transfer learning
- Ordinal DR grading
- Model calibration
- Confidence estimation
- Referral mechanism
- Explainable AI
- Streamlit application
